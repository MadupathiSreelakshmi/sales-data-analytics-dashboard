# 📊 Sales Data Analytics Dashboard using Power BI

## 📌 Project Overview
Developed an interactive Power BI dashboard to analyze retail sales performance using the Superstore dataset. The dashboard provides insights into sales trends, regional performance, customer segmentation, and product-wise profitability to support data-driven business decisions.

---

## 📁 Dataset Information
- Dataset: Superstore Sales Dataset
- Records: 700+ sales records
- Features:
  - Category
  - Sub-Category
  - Region
  - Segment
  - Sales
  - Profit
  - Quantity
  - Order Date

---

## 📊 Key Insights
- Technology category contributed the highest profit (~35–40%)
- West region generated the highest sales performance (~30%+)
- Consumer segment accounted for nearly 50% of total sales
- Top 10 products contributed significantly to total revenue
- Identified regional and category-wise sales trends using data visualization
